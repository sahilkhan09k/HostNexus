# HOW TO REMOVE .MD FILES FROM GITHUB (KEEP LOCALLY)
# ═══════════════════════════════════════════════════════════════

## Step 1: Remove files from Git tracking (but keep locally)
git rm --cached *.md
git rm --cached context/*.md -r
git rm --cached specs/*.md -r
git rm --cached Six-File+Context+Methodology/*.md -r
git rm --cached apps/web/CLAUDE.md
git rm --cached apps/web/AGENTS.md

## Step 2: Re-add README.md (we want to keep this)
git add README.md

## Step 3: Commit the removal
git commit -m "chore: remove documentation files from tracking (keep README.md)"

## Step 4: Push to GitHub
git push origin main

# ═══════════════════════════════════════════════════════════════

✅ Removes .md files from Git tracking (won't be pushed anymore)
✅ Keeps the files on your local computer
